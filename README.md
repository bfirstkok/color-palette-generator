# color-palette-generator 🎨

Generate beautiful color palettes with multiple harmony modes. Click any swatch to copy its hex code.

## Features

- 5 harmony modes: Random, Analogous, Complementary, Triadic, Monochromatic
- Press **Space** to generate a new palette
- Click any swatch to copy its hex code
- Export palette as CSS custom properties (`--color-1` … `--color-5`)
- Hover to expand a swatch and see hex + RGB values

## Usage

Open `index.html` in any browser.
